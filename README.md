# meta-ads-pro-kit

Meta (Facebook/Instagram) 広告を、AI（Claude Code）で **作って・運用する**ための、プロのキットです。
広告APIを叩く「手」（[meta-ads-mcp](https://github.com/koji-hirayama-takea/meta-ads-mcp)）に対して、このキットが
「**広告の中身を作る（creative）**」と「**事故らせず成果を出す運用（ops）**」の2つの頭脳を足します。

> 道具（MCP）だけでは成果は出ません。**作る型**と**運用する型**があって、はじめて回ります。
> このキットは、その型を AI に実行させる2つのスキルです。

---

## 2つのスキル

```
meta-ads-pro-kit/
├── meta-ads-creative/   ← 広告クリエイティブ（画像）を作る
│   ├── SKILL.md            dual-reference 方式（ブランド一貫 × 写実UI）
│   ├── config.example.md   あなたのブランド素材を入れる
│   └── references/         手法 / プロンプト / バックエンド / 検収
└── meta-ads-ops/        ← 事故らせず成果を出す運用
    ├── SKILL.md            配信前監査 / 学習フェーズ / 判断ルール / 運用ループ
    ├── config.example.md   あなたの事業の値を入れる
    └── references/         監査 / 学習 / ルール / ループ / 用語
```

- **meta-ads-creative**：訴求を渡すと、ブランドの世界観を保ったまま広告画像を作る型。画像生成は Codex CLI（サブスク枠内・追加課金なし）か gpt-image-2 API（量産・最終品質）を選べる
- **meta-ads-ops**：配信前の点検、学習フェーズの扱い（触っていいタイミング）、入札やターゲの判断、日次/週次/月次の運用を AI に実行させる型

---

## これは「型」であって「秘伝の数値・勝ち素材」ではありません

このキットが渡すのは、**どの事業でも通用する方法論（method）**です。
「どの予算・入札・オーディエンスが勝つか」「どんなクリエイティブが当たるか」といった**個別の正解は入っていません**。
それは事業ごとに違い、あなたが運用しながら育てる部分だからです。

自社の値・素材は、各スキルの `config.example.md` を `config.md` にコピーして入れます。

---

## インストール

### かんたん（おすすめ）：AIに「セットアップして」と頼む

このフォルダを置いて Claude Code を開き、こう言うだけです。

> 「このキットをセットアップして」

同梱の `CLAUDE.md` を読んだAIが、**2スキルの導入 → config 作成 → 広告操作の土台（meta-ads MCP）が未導入なら clone してそのセットアップまで**、順番に手伝ってくれます（Meta側のトークン発行だけは、Metaの画面での操作が必要なのでAIが案内します）。最後に Claude Code を再起動すれば完了です。

### 手動でやる場合

1. このリポジトリを取得（GitHub からダウンロード or clone）
2. `meta-ads-creative/` と `meta-ads-ops/` を、あなたのプロジェクトの `.claude/skills/` 配下にコピー
3. 各スキルの `config.example.md` を `config.md` にコピーし、自社の値・素材を記入
4. 広告操作には [meta-ads-mcp](https://github.com/koji-hirayama-takea/meta-ads-mcp) が必要なので、未導入なら先にセットアップ
5. Claude Code を再起動 → スキルが認識される

## 使い方（話しかけるだけ）

**作る（creative）**
- 「この訴求で広告画像を作って」→ ブランド素材を使って、写実UI＋ブランドキャラの広告を生成

**運用する（ops）**
- 「配信を始める前に、設定を点検して」→ 配信前監査 → GO/NO-GO
- 「今この広告セットいじって大丈夫?」→ 学習フェーズで判断
- 「今週の振り返りして」→ サンプル数を踏まえて勝ち負けを整理

> 🚨 画像生成API（gpt-image-2 等）は従量課金です。課金が発生する生成は、実行前に必ず確認してください。Codex CLI 経由はサブスク枠内で使えます。
