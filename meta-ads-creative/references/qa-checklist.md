# クリエイティブ検収チェックリスト

生成した広告画像を入稿する前に、上から確認する。1つでも崩れていたら作り直す。

## ブランド
- [ ] ブランドキャラ/ロゴが、参照1と**同じ見た目**になっている（毎回別物になっていない）
- [ ] ブランドの差し色が、強調キーワード1つに使われている（全部に色を付けていない）
- [ ] ブランド名/ロゴが正しく入っている

## 品質
- [ ] UIが **photo-realistic**（影・グラデ・余白があり、安っぽいイラスト調になっていない）
- [ ] **テキストが崩れていない**（特に日本語。読めない字がない）
- [ ] 大見出しが大きい（画面上部 ~1/4）、短く読みやすい

## 伝わるか
- [ ] **1画像1メッセージ**（複数の訴求を詰め込んでいない）
- [ ] 具体的な体験が見える（ユーザーの問い → 製品の答え → 次の行動）
- [ ] 視線が「見出し → ビジュアル → CTA」で流れる
- [ ] CTAボタンが下部にあり、行動を促す形

## スマホ
- [ ] スマホサイズに縮小しても、見出しとCTAが読める
- [ ] 余白・改行が不自然でない

## 権利・安全
- [ ] 連携先などの**実在ロゴをそのまま描いていない**（一般化したラベルになっている）
- [ ] 実在の人物写真・顔を使っていない（生成された写実的な顔も避ける）

## 入稿
- [ ] サイズは正方形（1024×1024 or 1080×1080）
- [ ] OK なら meta-ads MCP の `upload_ad_image` → `create_ad_creative` で入稿
